# Messungen / Measurements / Ölçümler

Hier kommen die eigenen Messdaten aus dem Praktikum hin, Fotos in [`Fotos/`](Fotos/).
*Our own lab data goes here, photos into `Fotos/`. / Deneyde aldığımız ölçümler buraya, fotoğraflar `Fotos/` klasörüne.*

- `6.1_*` – I-U-Kennlinien (Plotter-Scans, Oszilloskop-Fotos) für R1, R2, R3, R_V
- `6.2_*` – Optischer Speicher (Spannung U_AB beim Schalten, Beobachtungen)
- `6.3_*` – Schmitt-Trigger (Dreieck 50 Hz, Rechteck 50 Hz / 2 kHz)
- `6.4_*` – RS-Flipflop (gewähltes R_V, Wahrheitstabelle)

`Fotos/Anleitung_*.png` sind die Gerätefotos aus der Versuchsanleitung (Netzgerät, XY-Plotter, Funktionsgenerator, Oszilloskop).
*`Anleitung_*` are the equipment photos from the lab manual. / `Anleitung_*` föydeki cihaz fotoğraflarıdır.*

Potentiometerstellungen (%) immer mitnotieren! · *Always note the potentiometer positions! · Potansiyometre konumlarını mutlaka not et!*
