### Ordnerstruktur pro Versuch

| Ordner | Inhalt |
|---|---|
| `01_Unterlagen` | Originalunterlagen des Lehrstuhls (Versuchsanleitung, Protokollvorlage) |
| `02_Vorbereitung` | Task und Fragen mit ausgearbeiteten Lösungen, DOCX + PDF |
| `03_Erklaerung` | Erklärung: Ziel, Prinzip, Durchführung, Anwendungen – **PDF auf Deutsch, Englisch und Türkisch** |
| `04_LTspice` | `Kurs-Modelle` (Originaldateien), `Demo` (fertige Schaltpläne zum Vorführen), `Netlisten` |
| `05_Simulationsergebnisse` | Diagramme aus LTspice |
| `06_Auswertung` | Excel-Vorlage mit Formeln für die Auswertung (Versuche 1, 2, 4, 5, 6) |
| `06_Protokoll` | Protokoll (Vorlage mit ausgefüllten Simulationen, später die Endfassung) |
| `07_Messungen` | Eigene Messdaten; `Fotos/` für Fotos vom Aufbau, Oszilloskop und Plotter |

### Arbeitsablauf
1. Vor dem Versuch: Erklärung lesen, Task durcharbeiten, LTspice-Demos ausprobieren.
2. Während des Versuchs: Messwerte in `07_Messungen`, Fotos in `07_Messungen/Fotos`.
3. Danach: Protokoll in `06_Protokoll` fertigstellen und die Tabelle oben aktualisieren.
4. Neuer Versuch: Ordner `Versuch-0X_Titel` mit derselben Struktur anlegen und die Zeile in der Tabelle verlinken.

**LTspice:** kostenlos von Analog Devices (getestet mit Version 26.1). Schaltplan in `04_LTspice/Demo` öffnen und auf **Run** klicken; die passende `.plt`-Datei richtet das Diagramm automatisch ein.

| Klasör | İçerik |
|---|---|
| `01_Unterlagen` | Kürsünün resmi dokümanları (deney föyü, rapor şablonu) |
| `02_Vorbereitung` | Task ve sorular, cevaplarıyla birlikte, DOCX + PDF |
| `03_Erklaerung` | Açıklama: amaç, mantık, yapılış, ileride ne işe yarar – **Almanca, İngilizce ve Türkçe PDF** |
| `04_LTspice` | `Kurs-Modelle` (orijinal dosyalar), `Demo` (deneyde gösterilecek hazır şemalar), `Netlisten` |
| `05_Simulationsergebnisse` | LTspice grafikleri |
| `06_Protokoll` | Rapor (simülasyon kısmı doldurulmuş şablon, sonra son hali) |
| `07_Messungen` | Kendi ölçümlerimiz; `Fotos/` klasörü deney düzeneği, osiloskop ve plotter fotoğrafları için |

### Çalışma düzeni
1. Deneyden önce: açıklamayı oku, Task'ı çalış, LTspice demolarını dene.
2. Deney sırasında: ölçümler `07_Messungen`'e, fotoğraflar `07_Messungen/Fotos`'a.
3. Deneyden sonra: raporu `06_Protokoll`'de bitir ve yukarıdaki tabloyu güncelle.
4. Yeni deney: aynı yapıda `Versuch-0X_Baslik` klasörü aç ve tablodaki satırını linkle.

**LTspice:** Analog Devices'tan ücretsiz (26.1 sürümüyle test edildi). `04_LTspice/Demo`'daki şemayı aç ve **Run**'a bas; aynı isimli `.plt` dosyası grafiği otomatik ayarlar.
